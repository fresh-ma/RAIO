# RAIO — 科研助手平台

> 一个为学术工作者设计的 AI 驱动全流程科研伴侣，集论文管理、学习规划、前沿资讯、多 Agent 对话于一体。

---

## 它是什么？

RAIO（取自 Radar + AI + Odyssey 的首字母组合）是一个面向科研人员的个人智能工作站。如果你每天要在搜论文、做笔记、找学习路径、盯 arXiv 更新之间反复横跳，RAIO 就是为这种生活而造的。

它不是一个聊天机器人，也不是一个简单的待办 App——它是一个由六位性格各异的 AI Agent 组成的"智慧团队"，每位 Agent 各有所长，共享同一套对你的了解，协同帮助你完成从阅读到学习、从信息获取到知识沉淀的完整闭环。

---

## 核心理念

**知识应该流动，而不是沉睡。**

很多研究者有这样的困惑：收藏了几百篇论文，却不知道从哪里开始读；学了一个知识点，几个月后发现自己完全不记得了；每天看到 arXiv 的新动态，不知道哪条对自己的方向有用……

RAIO 的设计出发点，就是把这些零散的行为——阅读、笔记、对话、学习——统一纳入一套"全局记忆"体系。你做的每一件事都会积累成你的画像，你问的每一个问题都能被 Agent 联系到你过去的阅读和学习。随着使用时间增长，它对你的理解也会越来越深。

## 功能模块

### 🤖 首页 · 多 Agent 智能对话

这是 RAIO 的门面，也是使用最频繁的地方。你可以在这里向六位 Agent 提问：

| Agent | 代号 | 性格 | 擅长方向 |
|-------|------|------|----------|
| 洛墨 / Lumo | 调度精灵（男） | 沉稳、专业、带一点幽默 | 意图理解、综合问答 |
| 鸮言 / Hoot | 调度精灵（女） | 活泼、聪慧、灵动 | 意图理解、综合问答 |
| 书蠹 / Bookworm | 论文 Agent | 亲切、博学 | 论文搜索策略、摘要解读、文献推荐 |
| 学者 / Scholar | 学习 Agent | 有条理、耐心 | 学习计划制定、知识点拆解、出题测验 |
| 花匠 / Bloom | 生活 Agent | 温暖、治愈 | 待办管理、情绪疏导、科研生活平衡 |
| 齿轮 / Gears | 技术 Agent | 精准、高效 | 编程辅助、服务器运维、技术方案 |

默认模式下，系统会根据你的消息内容**自动路由**到最合适的 Agent（例如问"最近有什么 RAG 新论文"会自动转给书蠹，说"感觉好累"会交给花匠）。你也可以手动切换，把某个 Agent 固定为当前对话对象。

对话采用 **SSE 流式输出**，回复实时逐字呈现，不需要等待。

聊天界面右侧还有两个常驻面板：
- **能力雷达**：用六边形图直观展示你在文献力、学习力、前沿力、推演力、行动力、表达力六个维度的成长曲线。
- **待办事项**：快速记录当下最重要的事，完成时会触发经验奖励。

### 📚 图书馆 · 论文管理与 AI 伴读

图书馆是你的论文收藏中心，同时也是一个主动帮你读懂论文的伙伴。

**你可以做的事：**
- 搜索 arXiv 上的论文（直接调用 arXiv API，实时结果）
- 一键收藏感兴趣的论文
- 为每篇论文写随想、摘录、批注
- 请 AI（书蠹）生成一份结构化的论文伴读总结

**AI 伴读总结**的格式是固定的，包括：
- **TL;DR**：用 1-2 句话说清楚这篇论文在做什么
- **核心贡献**：3 个要点，每点都附有摘要中的依据
- **方法与实验线索**：帮你梳理可能的研究路径
- **局限与追问**：指出哪些问题需要读原文才能确认

这个设计避免了"AI 帮你一步到位读论文"带来的浅层理解问题——总结是引导你去读，而不是替你读。

每次收藏论文、写笔记，都会计入全局记忆，此后 Agent 在对话中可以主动引用你收藏过的内容，给出更有针对性的回答。

---

### 🎓 大师之路 · AI 生成学习路径

输入一个主题（比如"机器学习"、"线性代数"、"Docker 部署"），学者 Agent 会为你生成一份完整的**分章节学习大纲**，每个章节包含：

- 章节标题与核心逻辑（为什么学这一章）
- 难度等级（1–5 星）
- 预计学习时长
- 具体知识点列表
- 外部资源链接（B 站、YouTube、菜鸟教程等搜索链接，不会编造不存在的课程）

学习路径不是静态文档，而是一张可以被激活的地图。每个章节节点都可以被标记为**学习中 / 已完成 / 待复习**，整体进度以百分比呈现。

**随堂测验**功能让你不只是看，而是真正检验。点击章节旁的"测验"按钮，学者 Agent 会即时生成 4 道选择题，提交后可以看到逐题解析和得分。通过测验（60 分以上）会点亮该章节节点，并触发"初试锋芒"成就。

---

### 📰 八卦早知道 · 前沿资讯 + AI 解析

这里每日聚合来自 arXiv cs.AI 方向的最新学术动态，同时提供**AI 每日晨报**——由 Agent 自动将当天资讯提炼为 3 条摘要，方便快速浏览。

当你看到一条感兴趣的资讯，可以点击"AI 解析"，系统会调用大模型对这篇文章进行深度分析，还支持在弹窗内直接**追问**，和 AI 围绕这条资讯展开讨论。

更有意思的是"**关注联动**"功能：点击关注后，系统会自动在 arXiv 上找到与这条资讯最相关的论文，直接收录到你的图书馆，同时创建一条对应的微学习路径（含 3 章节）放入大师之路——一个动作打通三个模块，让新闻不只是看过就忘。

![RAIO 新闻关注跨模块联动工作流](doc/assets/raio-stardew-workflow.svg)

如果网络不佳导致 arXiv 无法访问，系统会自动切换到离线占位资讯，保证页面始终可用，刷新后恢复正常。

### 🌱 生活驿站 · 日常管理与情绪空间

生活驿站是一个相对轻量的模块，由花匠 Agent 主导。这里的定位不是"任务管理系统"，而是一个让你稍微喘口气、整理自己状态的地方。花匠会关心你的情绪，在你说自己很焦虑的时候给予安慰，在你完成一件大事的时候认真地道一声恭喜。

### 🧠 全局记忆与能力雷达（技术亮点）

这是 RAIO 区别于普通 AI 工具的核心机制。

**全局记忆（Global Memory）**是一套轻量级的 RAG（检索增强生成）系统，运行在本地 SQLite 数据库中。你在平台上的所有有意义行为——收藏论文、写笔记、完成学习节点、新增待办、与 Agent 对话——都会被记录为带权重的"记忆事件"，并附上来源类型和标签。

每次你和 Agent 对话时，系统会对你的问题进行分词，从记忆库中检索最相关的片段（综合关键词匹配分、时间新鲜度、事件权重），把前 6 条最高分的记忆作为上下文注入到 Agent 的 system prompt 中。Agent 拿到这些线索时，会谨慎使用——"如果片段不足以支撑结论，要明确说'不足以判断'"，避免幻觉。

**能力雷达**则是对你全部行为的定量评估，六个维度分别对应不同类型的行动：

| 维度 | 颜色 | 获得方式（举例） |
|------|------|----------------|
| 文献力 | 青绿 | 收藏论文、写笔记 |
| 学习力 | 嫩绿 | 创建学习路径、通过测验 |
| 前沿力 | 金黄 | 阅读新闻、关注联动 |
| 推演力 | 薰衣草 | 与 Agent 聊天、生成总结 |
| 行动力 | 蓝色 | 完成待办、推进学习进度 |
| 表达力 | 橙黄 | 写论文笔记、与 Agent 深度交流 |

每个维度有独立的 EXP 数值，经过对数曲线转换为 0–100 的"雷达分"，画成六边形直观呈现。EXP 会在你第一次登录时根据历史数据补算基线，避免"从零开始"的挫败感。

### 🏆 成就系统

RAIO 内置了 10 个成就，覆盖从首次登录到深度使用的完整旅程。成就系统的目的不是让你刷分，而是在你完成一件值得记录的事时，给你一个小小的正向反馈：

- 🏠 **初来乍到** — 首次登录
- 💬 **打开话匣子** — 第一次与 Agent 聊天
- 📚 **点亮图书馆** — 收藏第一篇论文
- 📝 **笔记小能手** — 给论文写第一条笔记
- ✅ **立志之人** — 添加第一个待办
- 🔥 **天选打工人** — 待办超过 7 个
- 🎓 **学海无涯** — 开始第一个学习路径
- ⚔️ **初试锋芒** — 完成第一次测验
- 📖 **论文收藏家** — 收藏 5 篇论文
- 🗣️ **话唠学者** — 与 Agent 聊天超过 10 次

## 技术架构

### 前端

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18.x | UI 框架 |
| Vite | 6.x | 构建工具 |
| React Router | 6.x | 单页应用路由 |
| TailwindCSS | 3.x | 样式系统 |
| react-markdown | 9.x | Markdown 渲染 |

前端以像素风（Pixel Art）为视觉语言，灵感来自《星露谷物语》的田园美学——深色背景、暖色调文字、像素边框。整体风格刻意保留手工感，避免科技产品的冷漠感。

### 后端

| 技术 | 版本 | 用途 |
|------|------|------|
| Node.js + Express | 4.x | API 服务器 |
| sql.js | 1.x | SQLite（纯 JS，无需 native 依赖） |
| JWT | — | 用户认证 |
| bcryptjs | — | 密码加密 |
| SSE（Server-Sent Events） | — | 流式 AI 输出 |

数据库选用 **sql.js**（SQLite 的 WebAssembly 版本），无需安装任何系统级依赖，数据库以单文件 `data/raio.db` 形式持久化，每 5 秒自动备份一次，用户每次关键操作后也会立即触发保存。

### AI 接入

RAIO 接入华为 **ModelArts MaaS** 平台，支持 DeepSeek、Qwen、Kimi 等多个主流大模型。用户在登录时需要填写自己的 MaaS API Key 并选择模型；后端只校验并转发本次请求携带的 Key 和模型，不会把用户 Key 存入服务器数据库。

默认模型是 `deepseek-v4-flash`。如果用户在个人页修改模型，后续 Agent 对话、论文总结、学习路径生成、新闻解析都会使用新的用户选择。

## 快速开始

### 环境要求

- Node.js 18+
- npm 8+

### 安装

```bash
git clone <仓库地址>
cd RAIO
npm install
```

### 配置

```bash
cp .env.example .env
```

打开 `.env`，至少需要设置：

```env
# MaaS API 地址（默认已填好华为 MaaS 地址）
MAAS_API_URL=https://api.modelarts-maas.com/v2/chat/completions

# JWT 签名密钥（请修改为随机字符串）
JWT_SECRET=your-secret-here
```

> **注意**：用户的 MaaS API Key 由用户在登录界面自行填写，不需要在 `.env` 里配置。

### 启动

```bash
npm start
```

这会同时启动后端（默认端口 3001）和前端开发服务器（默认端口 5173）。打开浏览器访问 `http://localhost:5173` 即可。

也可以分开启动：

```bash
npm run server   # 仅启动后端
npm run dev      # 仅启动前端
```

### 注册账号

首次使用需要注册，用户名为 3-12 位字母数字，密码为 8-15 位字母+数字组合。注册完成后，在登录页填入你的华为 MaaS API Key，选择一个模型，即可进入主界面。

## Agent API 端点独立配置（可选）

如果你需要把不同 Agent 路由到不同 MaaS 网关或代理端点，可以在 `.env` 中按以下格式添加覆盖配置：

```env
# 给书蠹配置独立 API 端点
MAAS_API_URL_BOOKWORM=https://api.modelarts-maas.com/v2/chat/completions

# 给学者配置独立 API 端点
MAAS_API_URL_SCHOLAR=https://api.modelarts-maas.com/v2/chat/completions

# 给齿轮配置独立 API 端点
MAAS_API_URL_GEARS=https://api.modelarts-maas.com/v2/chat/completions
```

模型本身始终以用户登录或个人页中选择的模型为准；未配置端点的 Agent 会使用 `MAAS_API_URL`。

## 数据说明

所有用户数据存储在本地 `data/raio.db`（SQLite 文件），包含：

- 用户信息与认证
- 聊天历史（每用户最多显示最近 50 条）
- 收藏的论文与笔记
- 学习路径与进度
- 待办事项
- 全局记忆事件
- 能力雷达 EXP 数值
- 成就解锁记录

**没有任何数据上传到外部服务器**，除了必要的：大模型 API 调用（你的对话内容会发送给 MaaS 平台）和 arXiv 论文搜索（公开 API，无认证信息）。

## 写在最后

RAIO 的名字里藏着一个小小的野心：**Radar + AI + Odyssey**——用雷达扫描你的知识边界，用 AI 陪你踏上这段探索之旅。

它不完美，有些边界很清晰：它不能帮你真正下载论文全文，不能替你做实验，Agent 的知识边界取决于背后的大模型。但它想做的，是让那些已经在发生的事情——阅读、思考、学习、记录——变得更有连续性，更有温度。
