# RAIO 2.0 改版方案：长在机构权限上的文献全文 Agent

> 回应评审意见的正式改版方案 · 2026-07

## 0. 一句话定位

**LLM 人人都有，但你的校园网和数据库账号只有本地 Agent 能用。**
RAIO 从"科研门户 + 聊天助手"升级为「凭证驱动的全文获取 + 证据链阅读」科研 Agent：
自动拿到论文 PDF（含付费全文）→ 结构化解析 → 每句结论可点击回溯原文 → 多篇对比与综述流水线。

## 1. 评审意见与对应策略

| 评审意见 | 对应策略 |
|---|---|
| 花园/心情与定位不符 | **直接删除**生活驿站模块，待办并入主页，开发量全部回收 |
| Agent 要做 LLM 做不到的事（本地凭证、登录数据库） | 新增**全文获取链**：本地加密凭证保管箱 + Playwright 自动登录 IEEE/ACM/Elsevier/知网 |
| 缺特色创新 | **证据链阅读**（句级可点击引用，反幻觉）+ 中文生态（知网）+ 凭证不出本机的隐私架构 |
| 缺效果评价 | 建立**五维评测体系**：获取成功率 / 抽取 F1 / 引用忠实度 / 端到端用户实验 / 消融 |

## 2. 砍掉什么

- `src/pages/LifePage.jsx`（花园种植、心情记录）及路由、导航入口 —— 全部删除。
- 待办功能保留（主页已有面板，`/api/todos` 不动）。
- 成就 / 能力雷达降级为轻量点缀，不再作为核心卖点宣传。

## 3. 三大新支柱

### 支柱一：全文获取链（核心护城河）

```
用户点「获取全文」
      │
      ▼
① arXiv 直链 PDF ──失败──► ② Crossref 补全 DOI
      │                          │
      ▼                          ▼
   下载成功              ③ Unpaywall / OpenAlex 开放获取版本
                                 │ 失败
                                 ▼
                       ④ 机构通道（Agent 做 LLM 做不到的事）
                          本地凭证保管箱 + Playwright 自动登录
                          IEEE Xplore / ACM DL / ScienceDirect / 知网
                                 │
                                 ▼
                       PDF 落盘 + 全过程 step 日志（供评测与审计）
```

**关键设计**
- **凭证保管箱**：数据库账号 AES-256-GCM 加密存本机 `data/vault.enc`，密钥文件权限 600，任何接口只返回掩码，绝不上云、绝不进 LLM 上下文。
- **降级链路**：优先开放获取，机构通道是最后一步——省流量、合规、也让无凭证用户可用。
- **全过程可审计**：每次获取返回 steps 轨迹（哪一步、成功与否、原因），直接服务评测。

**合规红线（写进产品文档）**
仅使用用户本人合法订阅；仅个人研究用途；请求限速；不绕过任何技术保护措施。这是与 Sci-Hub 式方案的本质区别，也是方案"高度"所在。

### 支柱二：证据链阅读（创新点，反幻觉）

- PDF 全文结构化解析（GROBID / 规则抽取）：方法、数据集、baseline、指标、结果表。
- AI 总结的**每句结论挂锚点**，点击跳转 PDF 原文页/段落——可验证、可追溯。
- 多篇论文自动生成**横向对比矩阵**（方法×数据集×指标）与 Related Work 草稿。
- OpenAlex 引用网络滚雪球，支撑半自动综述流水线。

### 支柱三：Agent 架构升级

关键词路由 → 真正的**工具调用循环（plan → act → verify）**：
浏览器自动化、PDF 解析、学术 API（arXiv/Crossref/OpenAlex/Unpaywall）都注册为工具，
LLM 负责规划与校验，工具负责执行。这才是"Agent"的技术含量所在。

## 4. 与同类工作对比

| | Elicit / SciSpace | PaperQA | GPT Researcher | **RAIO 2.0** |
|---|---|---|---|---|
| 全文来源 | 仅开放获取 | 需用户自备 PDF | 网页抓取 | **自动用机构凭证获取付费全文** |
| 运行位置 | 云端 | 本地 | 本地 | 本地（**凭证不出机**） |
| 证据可点击回溯 | 部分 | 有 | 无 | **句级证据链** |
| 中文生态（知网） | 无 | 无 | 无 | **有** |
| 获取过程可审计 | 无 | — | 无 | **step 级轨迹** |

## 5. 评测体系（回应评审 2）

| # | 维度 | 方法 | 指标 |
|---|---|---|---|
| 1 | 全文获取 | 固定 100 篇基准集（IEEE/ACM/Elsevier/arXiv/知网 各 20），跑三组：无凭证 / 有凭证 / 人工手动 | 成功率、平均耗时、各链路命中分布 |
| 2 | 结构化抽取 | 30 篇人工标注金标（方法/数据集/指标字段） | 字段级 Precision / Recall / F1 |
| 3 | 引用忠实度 | 生成结论 vs 锚点原文段落，人工核验 + NLI 自动判定 | 可支持比例（faithfulness %） |
| 4 | 端到端 | N≥6 名研究生同题综述任务：RAIO vs 裸 LLM vs Elicit，盲评 | 质量评分、完成时间 |
| 5 | 消融 | 仅摘要 vs 全文证据链，同一批问题 | 回答准确率差值（量化全文增益） |

基准集与评测脚本随仓库发布（`eval/` 目录），保证可复现。

## 6. 里程碑

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **P0**（本次） | 删生活模块；获取链后端（arXiv+Crossref+Unpaywall+OpenAlex 可用，机构通道骨架）；图书馆"获取全文"按钮；凭证保管箱 | OA 论文一键获取成功；凭证 CRUD 可用 |

## 7. 风险与对策

- **数据库反爬/验证码** → 限速 + 复用登录态（storageState）+ 失败即降级并提示人工；不做验证码破解。
- **各校认证方式差异** → 适配器插件化（每个 provider 一个文件），社区可贡献。
- **模型输出 JSON 不稳（已知问题）** → 工具调用循环 + JSON schema 校验重试，替代裸正则解析。
