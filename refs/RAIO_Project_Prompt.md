# 🧬 RAIO — Research All-in-One 科研生存套件

> **一句话定位**: 给每一个博士生/科研人一个 24 小时在线的科研搭子——能帮你读论文、看服务器、做规划、治焦虑。
> **一句话美学**: 星露谷物语 × 科研实验室 —— 像素温暖感 + 功能硬核感。你的科研生活，是一场值得好好经营的游戏。

---

## 0. 产品哲学 (读完再动手)

这不是一个"功能堆砌的 Dashboard"。这是一个 **有人格的科研伙伴**，生活在一个像素风的温暖世界里。

**核心信念**:
- 科研最大的痛苦不是技术，是**孤独感和失控感**。凌晨三点 debug 没人问、paper 被拒不知道找谁聊、DDL 堆在一起喘不过气——RAIO 要解决的是这些。
- 每个功能模块不是孤立的工具，而是 **一个有温度的 Agent 人格的不同侧面**。它会在你读完 5 篇论文后说"该喝水了"，会在你服务器跑了 72 小时后提醒"实验可能该收了"。
- **为什么是星露谷?** 因为星露谷的核心精神就是: 把日复一日的劳作变成有成就感、有节奏、有惊喜的生活。科研也一样。我们不美化科研的苦，但我们让经营科研生活这件事本身变得可爱。

**设计原则**:
1. **Zero-friction**: 不要让用户配置任何东西才能开始用。第一次打开就有价值。
2. **Contextual Intelligence**: 模块之间信息互通。论文 Agent 发现的 SOTA 方法可以直接推给 Learning Agent 去生成学习路径。
3. **Emotional Awareness**: 不做冷冰冰的工具人。根据用户行为模式（深夜活跃、频繁切换任务、长时间无产出）给出**恰当的关怀**，不是烦人的弹窗。
4. **游戏化但不幼稚**: 像素风、成就系统、Agent 换装——这些是让枯燥的科研日常多一点期待感，不是把用户当小孩。

## 1. 技术栈 & 架构

```
Framework:  React 18 + TypeScript
Styling:    Tailwind CSS (自定义 design tokens) + 像素风 CSS 系统
Pixel Art:  纯 CSS/SVG 实现 (不依赖外部图片资源, 用 box-shadow pixel art 技术或 SVG)
State:      Zustand (轻量、跨组件共享)
Router:     内置 Tab/View 切换 (单页应用, 不用 react-router)
API 调用:   Anthropic API (claude-sonnet-4-20250514) 作为所有 Agent 的大脑
外部 API:   arXiv API, 各类公开 API
存储:       window.storage (持久化用户数据跨 session)
字体:       "Press Start 2P" (标题/像素风元素) + "Noto Sans SC" (正文可读性)
```

## 2. 界面设计 — 星露谷物语 × 科研实验室 (核心重点!!!)

### 2.1 整体美学方向: **"像素科研小镇"**

想象你走进一个像素风格的科研实验室/图书馆。窗外是星空，桌上有台灯和咖啡杯，书架上堆满论文。每个 Agent 是这个小镇里的一个 NPC 居民，各有性格和穿着。

**不是简单贴个像素滤镜！而是:**
- 整体 UI 框架保持现代可用性 (清晰的布局、可读的正文)
- 在关键 **装饰元素** 上使用像素风: Agent 头像、导航图标、状态图标、成就徽章、边框装饰

- 过场动画使用像素风格 (如翻页、星星闪烁)

### 3.4 像素 Agent 绘制技术方案

**方案: 纯 CSS box-shadow pixel art + React 组件化**

```jsx
// 每个 Agent 是一个 React 组件, 接受 outfit 参数
<PixelAgent 
  character="bookworm"
  hat="graduation_cap"     // 当前帽子
  outfit="academic_robe"   // 当前服装
  heldItem="book"          // 当前手持物
  size={32}                // 渲染尺寸 (32x32, 64x64 等)
  animation="idle"         // idle | talking | celebrating | thinking
/>
```

**像素绘制原理**: 使用 1px × 1px 的 `box-shadow` 铺设像素点。每个装扮是一个颜色矩阵 (数组)。通过叠加 base body + hat layer + outfit layer + item layer 实现换装。

```javascript
// 示例: 像素颜色矩阵
const BOOKWORM_BASE = [
  // 16x16 grid, 每个值是颜色或 null(透明)
  [null, null, '#6dc2ff', '#6dc2ff', ...],
  // ... 16 行
];

const HAT_GRADUATION = [
  // 只有帽子区域有颜色, 其余 null
  ['#333', '#333', '#333', ...],
  // ...
];

// 渲染时叠加所有图层
function renderPixelAgent(base, hat, outfit, item) {
  return mergeLayers([base, outfit, hat, item]);
}
```

**动画**: 通过 CSS `@keyframes` 实现:
- `idle`: 每 2 秒上下位移 1px (呼吸感)
- `talking`: 每 0.3 秒切换两帧 (嘴巴开合)
- `thinking`: 头上 "..." 气泡闪烁
- `celebrating`: 跳跃 + 星星粒子

## 4. 五大模块详细设计

---

### 📚 模块一: Paper Agent — "书虫"的图书馆

**核心体验**: 不是一个搜索框。是一个**能帮你做文献综述的搭子**。进入时，书虫站在一个像素书架旁边，朝你挥手。

#### 4.1 功能细节

**A) 智能论文检索 (不只是搜索)**

用户输入一个研究问题 (自然语言)，Agent 执行以下工作流:

```
Step 1: Query Decomposition (查询拆解)
  - 调用 Claude API 将用户问题拆解为 3-5 个互补的搜索角度
  - 书虫说: "嗯...让我从几个角度找找看..."
  - 例: "如何用 LLM 做代码生成" →
    - "large language model code generation"
    - "LLM program synthesis benchmark"
    - "neural code completion transformer"
    - "automated programming AI recent survey"

Step 2: Parallel Search (并行搜索)
  - 对每个子查询并行调用 arXiv API
  - 每个查询取 top 10 结果
  - UI: 每完成一个子查询, 书虫头上冒出一个 ✓

Step 3: Dedup + Relevance Ranking (去重 + 相关性排序)
  - 合并结果，去除重复
  - 调用 Claude API 对每篇论文的 title + abstract 做相关性打分 (1-10)
  - 按分数排序

Step 4: Result Synthesis (结果综合)
  - 生成一段 "文献地图" 总结: "这个领域的研究主要分为 X、Y、Z 三个方向..."
  - 标注关键论文、高引论文、最新论文
  - 书虫说: "找到了! 我给你整理了一份地图 📜"
```

**UI 展示**:
- 搜索结果以 **像素卡片列表** 呈现，每张卡片有像素边框
- 每篇论文卡片: 标题、作者、年份、摘要(可展开)、相关性评分(像素星星)、一键收藏(像素心)
- 顶部展示 Agent 生成的 "领域地图" 总结卡片 (特殊金色边框)
- 收藏时论文卡片飞向左侧导航栏的 Paper 图标 (像素动画)

**B) 论文阅读 & 问答**

- 用户可以输入 arXiv ID 或 URL 导入论文
- Agent 自动获取 abstract + 元信息 (通过 arXiv API)
- 提供 **结构化阅读模式**:
  - 一键生成: "3 分钟速览" / "方法论详解" / "和我的研究有什么关系"
  - 针对论文内容的自由问答
  - "帮我找到这篇论文的 limitation 和 future work"
- 问答以 **像素对话框** 形式展示，书虫在旁边做各种表情

**C) 论文收藏库 (Paper Vault)**

- 收藏的论文持久化存储 (window.storage)
- 像素风书架 UI: 每本论文是书架上的一本像素小书 (颜色按标签分类)
- 支持添加个人标签和笔记
- Agent 可以跨论文回答问题: "我收藏的论文里，哪些用了 Transformer 架构?"
- 定期提醒: "你收藏了 12 本书但只翻了 3 本，要不要今天消化一下? 📖"

### 🖥️ 模块二: Server Agent — "机械师"的控制室

**核心体验**: 一个像素风格的服务器控制室面板 + 自然语言运维助手。进入时，机械师站在一排像素服务器机柜旁。

#### 4.2 功能细节

> ⚠️ **重要**: 由于这是一个浏览器内 React 应用，**无法直接 SSH 连接服务器**。采用以下方案:

**方案: 粘贴解析 + 智能建议**

- 用户粘贴 `nvidia-smi` / `htop` / `ps aux` 的终端输出
- Agent 自动解析并生成 **像素风可视化仪表盘**:
  - GPU 卡片: 每张 GPU 是一个像素风"机器"，温度越高颜色越红 (绿→黄→橙→红)
  - 显存条: 像素风进度条，有分段动画
  - 进程列表: 像素风表格，按资源使用排序
  - 运行中的训练任务: 用像素齿轮转动图标标识
- 提供 **一键生成脚本** 功能:
  - 生成监控脚本 (可复制到服务器上 cron)
  - 生成 SSH 连接命令
  - 常用运维命令速查 (像素风命令卡片)

**UI 展示**:
- 顶部: 服务器状态概览 (像素风仪表盘)
- 中部: GPU 可视化 (每张卡一个像素机器图标, 状态灯)
- 底部: 和机械师对话 + 进程列表
- 空状态: 机械师说 "把你的 nvidia-smi 输出贴给我看看？"

**特色亮点**:
- 机械师会分析: "GPU 2 温度 89°C 🔥 兄弟，该关心一下散热了"
- "这个训练跑了 72 小时了，loss 最后输出是 3 小时前...可能卡住了？"
- 极端情况下机械师换上 "消防员装" (如果 GPU 温度 > 90°C)

### 🧠 模块三: Learning Agent — "学者"的魔法塔

**核心体验**: 给一个关键词，学者帮你铺设一条**从入门到精通的魔法路径**。进入时，学者站在一个像素风魔法阵旁。

#### 4.3 功能细节

**A) 学习路径生成**

用户输入: "我想学 LoRA 微调"

Agent 工作流:
```
Step 1: 知识图谱构建
  - 调用 Claude API 生成该主题的知识依赖图
  - 识别前置知识 (用户可能缺的)
  - 拆分为 5-8 个递进的学习阶段
  - 学者说: "让我看看你的知识地图...✨"

Step 2: 内容聚合
  - 为每个阶段生成:
    - 📖 核心概念讲解 (Agent 自己写，简洁有力)
    - 🔗 推荐资源 (经典论文、知名博客、GitHub repo)
    - 💻 动手练习 (代码片段 / 思考题)
    - ✅ 阶段检测 (3-5 道选择/简答题)

Step 3: 个性化调整
  - 根据用户背景调整难度
  - "你说你熟悉 PyTorch，那我跳过基础张量操作"
```

**UI 展示 — 像素 RPG 地图风格**:
- 学习路径呈现为一条 **像素冒险地图** (类似星露谷的矿洞层级):
  - Stage 1: "新手村" 🏘️
  - Stage 2: "概念森林" 🌲
  - Stage 3: "实践矿洞" ⛏️
  - Stage 4: "进阶深渊" 🕳️
  - Stage 5: "大师殿堂" 🏰
- 当前阶段的小人在闪烁，已完成的路上有像素足迹
- 右侧: 当前阶段的学习内容 (正常字体保证可读性)
- 完成阶段时: 像素烟花 + 经验值 +20 动画

**B) 阶段测验**

- 每个阶段结束后，学者说: "来吧，接受考验! 🧪"
- 3-5 道题，像素风选项按钮
- 通过: 金色星星 + 路径推进动画
- 未通过: 学者温和地说 "没关系，我们再看看哪里不太清楚"
- 全部通过: 获得一个 **像素成就徽章** (持久化存储, 可在个人资料展示)

**C) 学习档案**

- 持久化存储已完成的学习路径
- 像素风 "技能树" 可视化: 已点亮的技能发光
- 学习热力图 (类似 GitHub contribution graph, 但是像素格子)

### 🌱 模块四: Life Agent — "园丁"的温室花园

**核心体验**: 不是又一个 Todo App。是一个**像素花园**——你完成任务，花就会生长。进入时，园丁在一片像素花田里浇花。

#### 4.4 功能细节

**A) Calendar & Todo — 像素农场日历**

- 周视图日历: 每天是一个像素格子，有事件的日子上面有小图标
- Todo 列表: 每个任务前面是一颗像素种子，完成时变成像素花朵 🌸
- 支持添加事件 (时间、标题、类型: 科研🔬/生活🏠/社交👥/健康💪)
- 园丁每天早上给一段 "今日简报":
  - "早上好~ 今天有 2 个 DDL，下午有组会。我建议上午集中写论文 ✏️"
  - "你已经连续 5 天没有运动标记了，今晚去跑步好不好? 你的小花需要阳光呀 ☀️"

**B) 像素花园系统 (核心情绪玩法)**

- 用户的产出行为会让花园里 **长出像素植物**:
  - 完成一个 Todo → 长出一朵小花 🌷
  - 读完一篇论文 → 长出一棵小树 🌳
  - 完成一个学习阶段 → 长出一朵稀有花 🌺
  - 记录心情日记 → 花园里飞过一只蝴蝶 🦋
  - 连续 7 天活跃 → 花园出现一个小池塘 💧
- 花园是一个 **横向滚动的像素场景**, 随着用户使用不断丰富
- 长期不用 → 花草会"枯萎"(变灰)，但不会消失，回来浇水就恢复
- 花园状态持久化存储

**C) 情绪日记 & 关怀**

- 每天可选记录心情 (5 个像素表情: 😢😕😐😊😆)
- 园丁会回应，口吻像一个温柔的朋友:
  - "paper 被拒确实很难受。要不要聊聊 reviewer 的意见？有时候拒稿反馈其实是最好的肥料。🌱"
  - "连续三天阴天了呢...科研低谷是正常的，要不要今天给自己放半天假？花园也需要休息日。"
- 月度情绪回顾: 像素风月历，每天用颜色标注心情，形成一幅"心情画"

**D) Work-Life Balance 看板**

- 像素风柱状图: 本周时间分配 (科研/学习/社交/运动/休息)
- 每类用不同颜色的像素方块堆叠
- 园丁温和地给建议: "这周科研占了 85%...你的花园里社交花一朵都没有呢 😢"

## 8. 给 Agent 开发者的话

**你不是在做一个 Demo，你是在做一个科研人会截图发朋友圈的产品。**

星露谷之所以让人上瘾，不是因为种田本身有多好玩，而是因为 **每一天都有微小的进展和惊喜**。RAIO 也是如此——每读一篇论文是一颗星星，每完成一个 Todo 是一朵花，每学会一个知识是一个技能点。科研本身很苦，但经营科研生活可以很甜。

做到以下几点，这个项目就赢了:
1. **像素风不是噱头** — 它是让冰冷工具变得有温度的关键。但正文必须用正常字体保证可读性。
2. **打开就有 Wow** — 第一眼看到像素 Agent 朝你挥手，就知道这不是普通的工具。
3. **用了会上瘾** — 星星、换装、花园——这些是让人每天想回来的理由。
4. **真的有用** — 论文搜索要真的能搜到东西，学习路径要真的有质量。游戏化是外衣，功能是骨架。
5. **有灵魂** — 五个 Agent 不是五个功能入口，是五个有性格的朋友。
