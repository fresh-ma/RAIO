# 🎨 RAIO Agent 像素角色素材定义

> 每个角色为 16×16 像素网格，用 CSS box-shadow 渲染。
> null = 透明, 字符串 = 颜色 hex。
> Agent 开发时按此文件定义的颜色方案绘制像素矩阵。

## 角色设计指南 (给 Agent 开发者)

### 📚 书虫 (Bookworm) — Paper Agent
**特征**: 大圆眼镜 + 蓝色学术袍 + 手拿一本翻开的书
**表情**: 默认微笑, 思考时推眼镜, 找到论文时兴奋

```
视觉描述 (16x16):
- Row 1-3:  头发 (深棕), 微微蓬松
- Row 4:    眼镜框 (深灰) 横跨两只眼
- Row 5:    眼睛 (白底+黑瞳) 在眼镜后面, 小嘴
- Row 6-7:  脖子 + 学术袍领口 (蓝色)

- Row 10-12: 左手区域拿着一本小书 (白色+棕色书脊)
- Row 13-14: 袍子下摆
- Row 15-16: 小脚 (深色鞋)
```

**装扮变体色板**:
- 默认学术袍: `bookBlue` + `bookBlueDark`

## 动画帧定义

### idle (所有角色通用)
- Frame 1: 基础姿势
- Frame 2: 整体上移 1px (呼吸感)
- 周期: 2s, ease-in-out

### talking (说话时)
- Frame 1: 嘴闭合
- Frame 2: 嘴张开 (嘴部像素行变化)
- 周期: 0.4s

### thinking (思考时)
- 角色不变
- 头上方出现 "..." 气泡 (3个圆点依次闪烁)
- 周期: 1.5s

### celebrating (完成任务时)
- Frame 1: 基础
- Frame 2: 跳起 (上移 4px)
- Frame 3: 最高点 (上移 6px)
- Frame 4: 落回
- 同时: 周围出现 3-5 个像素星星粒子飞散
- 播放 3 次后停止

## 实现提示

1. **每个角色定义为一个 16×16 的二维数组**, 空位为 `null`, 有色位为 hex 字符串
2. **装扮是同尺寸的覆盖层**, 只在有改动的像素位填色, 其余为 `null`
3. **先画 base body → 再叠 outfit → 再叠 hat → 最后叠 heldItem**
4. **渲染时用 `useMemo` 缓存 box-shadow 字符串**, 只在装扮切换时重新计算
5. **像素尺寸建议**: 导航栏小人 `pixelSize=3` (48×48 显示), 换装预览 `pixelSize=5` (80×80 显示)
