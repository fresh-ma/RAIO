# RAIO2 进阶修改与重构方案

> 本文档基于 `RAIO2修改要求.pdf` 的基础需求进行了体验与架构层面的延伸，旨在解决现有 Bug 的同时，将 RAIO2 打造成体验更佳的一站式智能学术与学习助手。

## 一、 主页智能助手 (Nexus Assistant)

### 🔴 核心痛点

1. **状态易失性**：切换页面后聊天记录立即丢失，无法承接上下文。
2. **"伪"多智能体**：当前系统的 Agent 切换仅停留在前端图文层面，底层请求的模型（deepseek-v4-flash）、System Prompt 以及上下文环境并未实现物理与逻辑隔离。

### ✨ 改进与重构方案

1. **引入“记忆切片”与持久化对话**：
   - 增加**历史记录功能 (Sessions)**，利用本地存储 (localStorage/IndexedDB) 或后端数据库保存完整的用户对话与上下文，保证切换页面再切回时，对话无缝对接。
2. **真·无感动态路由 (Router Agent) 与底层模型映射**：
   - 在 `.env` 配置多个模型入口（如针对文科/理科/代码使用不同能力偏好的模型或配置）。
   - 通过前台总意图识别进行动态路由绑定，当用户点击特定 Agent 时，底层的 System Prompt 进行严格隔离替换。
3. **UI 级的感知增强 (Agent Dock)**：
   - 主页下方的 6 个 Agent 重构为类似 macOS 的动效 Dock 栏。
   - 当特定 Agent 激活时，给予明确的呼吸、亮起等动效反馈，甚至主题色无缝切换，给用户“我在和不同领域的专家群聊”的真实沉浸感。

## 二、 图书馆 (Library)

### 🔴 核心痛点

1. 读书笔记声称支持 Markdown 但实际缺乏有效的解析渲染引擎。
2. 缺少针对当前阅读文献的结构化大模型总结能力。
3. 缺失笔记或者文献的本地保存下载功能。

### ✨ 改进与重构方案

1. **接入全能型极客渲染引擎**：
   - 修复 Markdown 渲染组件，接入 `react-markdown` 配合 `remark-math` 和 `rehype-prism`。
   - 完美适配含有 **LaTeX 数学公式**和**代码块高亮**的学术笔记场景。
2. **分粒度的“AI 伴读”面板**：
   - 将简单的“总结”扩充为悬浮组件面板，支持不同维度的论文分析：
     - *一句话总结 (TL;DR)*
     - *核心创新点提炼 (Contributions)*
     - *方法局限性评估 (Limitations)*
3. **高颜值知识导出**：
   - 支持将原文、Markdown 笔记以及 AI 总结对话片段进行排版整合，提供“一键导出为 `.md`” 或“导出为 PDF” 的选项。

## 三、 大师之路 (Path to Mastery)

### 🔴 核心痛点

1. 生成的学习路径存在交互 Bug，子路径无法点击与展开。
2. 缺乏外部权威学习资源（如 Bilibili、Youtube、菜鸟教程等）的支撑，模块内容过于单薄。

### ✨ 改进与重构方案

1. **游戏化成长的“技能树 (Skill Tree)”UI 重构**：
   - 修复点击失效的嵌套逻辑，引入更直观的技能树状分支 UI。
   - **标签式专属内容页**：当用户点击某个子路径标签（Tag）或节点时，不再仅仅是展开嵌套列表，而是平滑弹出一个专属的内容页面（或侧边抽屉面板），内聚展示该节点的详尽知识点大纲与核心逻辑解析。
   - 用户可以勾选子节点的完成状态，并配有学习进度条 (Progress: X/Y)，提供类似“通关打怪”的游戏化正向反馈。
2. **AI 动态网络资源挂载**：
   - 在每个学习节点内部，结合外部检索 API 提供精准的第三方资源超链接推荐。例如：*“为您推荐：2个对应知识点的B站视频教程、1篇图文博客”*。
3. **随堂微测试 (Micro-quiz)**：
   - 增加阶段性知识点测试功能。由大模型自动生成相关的单选题或简答题，用户答对后方可点亮该领域的专有徽章。

## 四、 新闻视野 (News Radar)

### 🔴 核心痛点

1. 新闻数据接入断连，模块前端处于未渲染/呈现为空白的问题。

### ✨ 改进与重构方案

1. **打通数据并通过 AI 进行智能降噪**：
   - 修复新闻资讯 API 或 RSS 数据源的获取与渲染。
   - 在顶部增加“AI 每日晨报”特区：由大模型提取当天数十条资讯的核心重点，输出为“今天你需要知道的 3 件事”。
2. **构建资讯双向探讨的关联知识网**：
   - 为每一条新闻提供“AI 解析”按钮。用户不仅仅能阅读新闻，还能点击向 AI 追问：“这对我目前的研究领域有什么影响？”，打破资讯的单向吸收困境。

---

## 五、 实施建议与优先级 (Milestones)

1. **P0 (生存期修复)：** 修复当前导致功能不可用的恶性 Bug（Markdown 渲染修复、聊天页面状态保持、大师之路点击展开 Bug、新闻接口打通）。
2. **P1 (逻辑完善期)：** 实现 Agent Prompt 硬件隔离、多模型 API 接入与动态切换、增加图书 AI 总结与下载功能、补充外部学习链接。
3. **P2 (体验惊艳期)：** Agent 沉浸式 UI 动效、游戏化技能树构建、每日 AI 晨报生成引擎。

---

## 六、 终极展望：全局联动与知识打通 (Global Synergy)

打破各个子模块“各自为战”的孤岛状态，实现底层数据流通，将 RAIO2 升级为具有“全局连续记忆”的超体系统：

1. **全局大脑与内建 RAG (检索增强生成)**：
   - 主页助手不再局限于短期上下文，而是全局接入用户在《图书馆》积累的论文笔记及《大师之路》的学习进度数据库。
   - *应用场景*：用户可直接向主页 Agent 提问：“根据我昨天在图书馆看的那篇强化学习论文，今天《新闻视野》里提到的新算法有借鉴意义吗？”，系统自动串接个人知识库进行深度推演。
2. **行为自动化跨模块驱动 (Auto-trigger)**：
   - 让系统主动推着用户走，各模块彼此触发形成飞轮效应。
   - *应用场景*：用户在《新闻视野》中关注了某项颠覆性新技术，后台 Agent 自动提取并抓取核心文献存入《图书馆》稍后阅读，同时在《大师之路》中动态生成一条该技术的“微学习路径”待用户去点亮。
3. **全栈用户能力画像与动态雷达 (User Component Radar)**：
   - 将所有模块的学习交互行为全局数据化，打造动态发展的个人数字画像。
   - *应用场景*：不仅是在系统里做考题，连在《图书馆》总结长文、在《新闻》保持日常阅读等行为，都会转化为对应领域的经验值（EXP）。主页生成炫酷的“六边形能力雷达图”，让用户的每一分努力都收获可见的正向多巴胺反馈。
