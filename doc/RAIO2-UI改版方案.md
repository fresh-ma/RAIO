# RAIO2 UI 改版方案

> 设计原型专家团 · 画统筹汇编 | 日期：2026-07-08

---

## 一、设计目标

将 RAIO 从"像素游戏风科研玩具"重塑为一款**专业、可信赖、保有温度的科研全栈助手**。

| 维度 | 当前 (V1) | 目标 (V2) |
|------|-----------|-----------|
| 视觉语言 | 星露谷像素风，暗色默认主题 | Linear 式现代专业工具，亮色默认 |
| 字体 | Zpix 像素点阵 + Press Start 2P | Inter + PingFang SC / Microsoft YaHei |
| 配色 | 高饱和蓝/金/绿撞色 | 靛蓝主色 + 暖灰基底 + 琥珀暖色点缀 |
| 命名 | "八卦早知道""活着""花匠" | "学术动态""个人中心""调度助手" |
| 全局 CSS | `* { image-rendering: pixelated }` | 移除像素化渲染 |

## 三、设计系统：RAIO x Linear

从 71 套设计系统中选定 **Linear Design System**（匹配度 95%），定制为学术场景专用。

### 3.1 色彩系统

**主色 — RAIO Indigo**：学术权威感，略偏暖避免冰冷

```
50: #F0F4FF    100:#DFE6FF    200:#C2CDFE    300:#9FAEFC
400:#7A8CF8    500:#5C6CF5    600:#4651E8    700:#3640D3
800:#2D36A8    900:#242B85    950:#191E5E
```

**中性色 — Warm Gray**：微暖底色消解学术工具疏离感

```
0: #FFFFFF    50: #FAFAF8    100:#F4F3F0    200:#E9E7E3
300:#D3D0CB   400:#A7A39B    500:#86827A    600:#67635C
700:#53504A   800:#3C3A36    900:#292724    950:#141311
```

**辅助色 — Amber Warmth**：温暖琥珀，进度/高亮的温度锚点

```
50: #FFFBEB   100:#FEF3C7   200:#FDE68A   400:#FBBF24
500:#F59E0B   600:#D97706
```

**语义色**：Success `#22C55E` | Warning `#F59E0B` | Error `#DC2626` | Info `#0EA5E9`

**背景层级**：

| Token | Light | Dark | 用途 |
|-------|-------|------|------|
| `--bg-page` | Neutral-50 | Neutral-900 | 页面底色 |
| `--bg-surface` | White | Neutral-800 | 卡片/面板 |
| `--bg-sidebar` | Neutral-100 | Neutral-950 | 侧边栏 |
| `--bg-hover` | Neutral-100 | Neutral-800/60 | 悬停态 |
| `--bg-active` | Indigo-50 | Indigo-950/60 | 选中态 |

### 3.2 字体

```css
--font-sans: "Inter", -apple-system, BlinkMacSystemFont,
             "PingFang SC", "Microsoft YaHei", sans-serif;
--font-mono: "JetBrains Mono", "Fira Code", "Consolas", monospace;
```

字重：400 Regular / 500 Medium / 600 Semibold / 700 Bold（仅两档为主）

**排版尺度（16px 根字号）**：

| Token | 字号/行高 | 用途 |
|-------|----------|------|
| `label-xs` | 11px/1.0 | 时间戳 |
| `label-sm` | 12px/1.15 | 徽章 |
| `body-sm` | 14px/1.5 | 论文列表 ← 列表主力 |
| `body-base` | 15px/1.6 | 对话消息 |
| `body-md` | 16px/1.65 | 论文正文 ← 阅读主力 |
| `h4` | 17px/1.25 Semibold | 卡片标题 |
| `h2` | 26px/1.2 Bold | 页面标题 |

正文行宽上限 75ch（约 600px），适配长文阅读。

### 3.3 间距

基于 4px 基准：`0, 2, 4, 6, 8, 10, 12, 14, 16, 20, 24, 28, 32, 40, 48, 56, 64`

- 组件内：8-16px · 组件间：16-24px · 区块间：32-48px
- 内容区最大宽度 1280px 居中

### 3.4 圆角

| Token | 值 | 场景 |
|-------|-----|------|
| `xs` | 3px | 代码块、小标签 |
| `sm` | 5px | 按钮、输入框 ← 主力 |
| `md` | 8px | 卡片、下拉面板 |
| `lg` | 12px | 模态框 |
| `full` | 9999px | 药丸标签 |

### 3.5 阴影

极克制：`xs: 0 1px 2px .04` → `sm: 0 1px 3px .06` → `md: 0 4px 6px .05` → `lg: 0 10px 15px .05`

### 3.6 动效

| 时长 | 场景 |
|------|------|
| 50ms | 开关/checkbox |
| 100ms | hover 态 ← 最常用 |
| 150ms | 展开/折叠 |
| 250ms | 页面过渡/模态框 |

缓动默认 `cubic-bezier(0.4, 0, 0.2, 1)`。

## 四、关键组件规范

### 4.1 导航栏（Sidebar）

```
宽度: 240px（展开）/ 56px（折叠）
背景: --bg-sidebar，右边框 1px Neutral-200

导航项：高度 36px，圆角 5px，内边距 0 8px
  - 默认: 图标 Neutral-400，文字 body-sm Medium Neutral-600
  - hover: bg Neutral-200/60
  - active: bg Indigo-50，文字 Indigo-700，左侧 3px Indigo-500 竖线

折叠态: 仅图标 + tooltip
```

### 4.2 论文卡片

```
内边距 16px，背景 --bg-surface，边框 1px Neutral-200，圆角 8px

hover: 边框 Neutral-300 + shadow-xs (100ms)
active: 边框 Indigo-300 + bg Indigo-50

布局（纵向）:
  [标题]       h4 17px Semibold，2 行截断
  [作者+年份]  body-sm 14px Neutral-500，单行缩略
  [摘要]       body-xs 13px Neutral-600，2 行截断
  [标签行]     Indigo pill + Neutral 来源徽章
```

### 4.3 对话气泡

```
用户消息:
  bg Indigo-500，白色文字，右对齐，max 70%
  圆角 12/12/4/12（左下小圆角），内边距 10px 14px

AI 消息:
  bg Neutral-100（亮色）/ Neutral-800（暗色），左对齐，max 80%
  圆角 12/12/12/4（右下小圆角），内边距 12px 16px

code-inline: font-mono 13px，bg Neutral-200/60，圆角 xs
code-block: font-mono 13px，bg Neutral-800 白字，圆角 sm，12px 内边距
blockquote: 左边框 2px Indigo-300，左内边距 12px，Neutral-500

消息间隔: 同发送者连续消息 gap 2px，不同发送者 gap 12px

输入框:
  min-height 40px，max-height 160px，圆角 sm
  边框 1px Neutral-300，focus: 边框 Indigo-500 + Indigo-100 ring
```

### 4.4 数据表格

```
容器: 边框 1px Neutral-200，圆角 8px

表头:
  bg Neutral-50，下边框 1px，label-md 13px Medium Neutral-500
  uppercase tracking-wide，高度 40px，sticky top 0

数据行:
  高度 44px（紧凑）/ 52px（舒适），下边框 1px Neutral-100
  hover: bg Neutral-50，selected: bg Indigo-50 + 左边框 2px Indigo-500

空状态: "暂无数据"，body-base Neutral-400，32px 上下内边距
```

### 4.5 按钮

| 尺寸 | 高度 | 内边距 | 字号 |
|------|------|--------|------|
| sm | 28px | 0 10px | label-sm 12px |
| md | 36px | 0 16px | body-sm 14px |
| lg | 44px | 0 20px | body-base 15px |

**变体**：
- Primary：bg Indigo-500，白色 Semibold，hover Indigo-600，focus-ring 3px Indigo-100
- Secondary：透明 + 1px Neutral-300 边框，hover bg Neutral-50
- Ghost：透明，hover bg Neutral-100
- Destructive：bg Red-50，文字 Red-600，hover bg Red-100

## 六、从 V1 到 V2 的改动汇总

| 类别 | 改动项 | V1 | V2 |
|------|--------|-----|-----|
| 全局 | 渲染模式 | `image-rendering: pixelated` 全局 | 移除，恢复标准抗锯齿 |
| 全局 | 默认主题 | 暗色（`#1a1a2e`） | 亮色（`#FAFAF8`），暗色可选 |
| 字体 | 中文 | Zpix 像素点阵 | PingFang SC / Microsoft YaHei |
| 字体 | 英文 | Press Start 2P（题头）+ Zpix | Inter 系统栈 |
| 字体 | 等宽 | 未定义 | JetBrains Mono / Fira Code |
| 配色 | 主色 | `#6ea8fe` 蓝 | `#5C6CF5` 靛蓝 |
| 配色 | 中性色 | `#1a1a2e` / `#16213e` 深色 | Neutral-50 ~ 950 暖灰 |
| 配色 | 强调色 | 金色 `#e8b830` + 绿色 `#9bd67d` | 琥珀 `#F59E0B` + 语义色系统 |
| 导航 | 布局 | 水平顶栏（暗底像素按钮） | 垂直侧边栏 240px 或轻量顶栏 |
| 导航 | 命名 | 八卦早知道 / 活着 / 大师之路 / 花匠 | 学术动态 / 个人中心 / 学习路径 / 调度助手 |
| 卡片 | 样式 | 3px 实色硬边框，像素化 | 1px 细框 + 8px 圆角 + hover 微阴影 |
| 阴影 | 体系 | 无 | 5 级克制阴影 Token |
| 动效 | 体系 | 无系统化 | 50-250ms cubic-bezier 标准曲线 |
| 主页 | 布局 | 花园/成就/待办占据首屏 | 对话区 60% 首屏 + 快捷入口卡 |
| 组件 | 按钮 | 分散内联 style | 4 变体 × 3 尺寸系统 |
| 组件 | 对话 | 基础气泡 | 非对称圆角 + Markdown 子组件 |
| 组件 | 表格 | 无 | 完整数据表格规范 + sticky header |
| 图标 | 来源 | 像素 emoji | Phosphor Icons / Lucide 几何图标 |
